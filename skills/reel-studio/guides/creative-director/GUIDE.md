# Creative director references (vendored, partial)

> Attribution: the four reference files here are from creative-director by Serge Shima, https://github.com/smixs/creative-director-skill. Licence: CC BY 4.0. Details in `ATTRIBUTION.md`.

Insight mining, tension spotting, 20 ideation methods, the emotion tiers and six story structures (Story Spine, Sparkline, Freytag, Monroe, Pixar rules, Hero's Journey). Read them through `playbooks/story-engine.md`, which says when to use each. Only the four method files are included: they fix the most common weakness in reel scripts, the idea and its tension.

| File | Use it for |
|---|---|
| `insight-mining.md` | Before any idea: Pollard's four points, JTBD, **tension spotting** (cultural / category / human), HMW, abstraction laddering, assumption mapping, the insight quality test and the **"[Audience] wants X, but Y, because Z"** format |
| `methods-catalog.md` | Making 8+ concepts that really differ: SIT, SCAMPER, TRIZ, morphological, **bisociation**, random entry, forced connections, synectics, **reverse brainstorm, worst idea, provocation PO**, oblique strategies, six hats, Disney, Crazy 8s, starbursting, first principles. Pick one method from each of three families |
| `emotion-hierarchy.md` | Naming the target feeling: reject Tier 1 (plain happy/sad), aim for Tier 2 (specific) or Tier 3 (mixed, e.g. bittersweet pride) |
| `storytelling-frameworks.md` | Shapes with per-length timings: Story Spine (story reels), **Sparkline** (concept / argument reels), Freytag, Monroe, the Pixar rules (post-check), Hero's Journey with the customer as hero and the brand as the guide |

The step-by-step method that ties these together, plus the scoring rubric, is `playbooks/story-engine.md`.
