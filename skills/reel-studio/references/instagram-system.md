# The Instagram system around the reels

Useful ideas from Instagram prompt packs and creator tools, folded into this skill in our own words.

## The weekly loop

1. **Monday: batch.** Run `prompts/10-weekly-command-center.md` with the brand context block (`brand-context.md`) and last week's numbers. Output: the week's queue, ranked by expected impact and ease: for example 1 story reel, 1–2 concept reels, 2 carousels (`prompts/13-carousel.md`), and daily Stories.
2. **Produce** each reel with the studio loop (`../SKILL.md`). Reuse characters, sets and voices across a series to keep cost down.
3. **Package:** cover (`prompts/05`), caption, search line and hashtags (`prompts/09`), a pinned comment that asks about the viewer's own life.
4. **Publish** (owner): AI label on, auto captions off when captions are burned in, cover = frame 0 unless a designed cover tests better.
5. **48 hours later: measure.** The owner sends Insights screenshots; run `prompts/12-metrics-audit.md`. Log reach, 3-second hold, average watch time, completion, shares and sends, saves, follows and profile visits in your reel log.
6. **Change one variable** for the next reel (hook line, first frame, cover, pacing, length, caption opening, CTA). Note the hypothesis and the decision rule before posting.

## Formats, tests and growth

- Every reel names its **format** (concept reel, story reel, product reel, festival greeting) and **one test question**: the one change it tries and what you'll learn from it. Write both in `story.md` before any art.
- Keep one hook alternate for a later test.

## What to test first (one at a time)

| Variable | Version A | Version B | Decide by |
|---|---|---|---|
| First frame | the face in trouble | the stopwatch close-up with the face behind | 3-second hold |
| Hook line | a question ("How many people is 'all of us'?") | a stake ("If the food runs out…") | 3-second hold |
| Length | 25 s | 35 s | completion rate × average watch |
| Cover | frame 0 | a designed cover (prompts/05) | profile-grid taps, reach from profile |
| CTA | the brand's CTA | "send this to the one who keeps the accounts" | shares and sends |

## Rules carried over from the packs

- Build from audience language: comments and DMs become the next stories (`prompts/10` has the miner).
- A series gives every episode its own hook and a reason to watch the next one.
- Never fake engagement, mass-DM, buy followers or automate replies that pretend to be personal. Comment-to-DM flows are only for a real free resource and stay polite.
- Accessibility: readable contrast, on-screen words that carry the story muted, alt text in every caption file.
- Keep editable masters, exports and prompt versions; name files so winners can be reused.
