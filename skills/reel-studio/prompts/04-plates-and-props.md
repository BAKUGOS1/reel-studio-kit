# 04 · Plates, cutouts and props

For: the owner in Codex, for parallax shots and for objects the story holds up (a diary, a bill, a notepad).

## Empty plate (the room without the person)

```text
[STYLE LOCK — prompts/01]
Attach: the base frame of this shot.
The same room as the attached image, from the same camera position, with the same light, but with nobody in it.
The chair is empty, [the props stay where they were]. Fill where the person was with what would be behind them.
```

## Transparent cutout (the person alone)

```text
[STYLE LOCK — prompts/01]
Attach: the base frame of this shot and the character sheet.
The same person in the same pose, same size and position in the frame as the attached image, on a fully
transparent background (PNG with real alpha). Clean edges, no halo, no border, no shadow box. Nothing else in the
frame.
```

## A prop seen flat (to be written on in code)

```text
[STYLE LOCK — prompts/01, flat even light]
A single [old cloth-bound diary page / a vendor's carbon-copy bill / spiral notepad] seen flat from directly above,
[its condition: yellowed, a tea ring, folded twice]. Printed rules only; completely blank of words, numbers and
marks. Transparent background around it (PNG with real alpha).
```

Words, numbers and handwriting on props are added in code (a handwriting font such as Kalam), so they are always spelled right.
